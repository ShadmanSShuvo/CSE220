# 02: Practice Problems & Reference Workbooks

This directory contains targeted practice problem sets, analytical derivations, code implementations, and visual demonstration suites across three foundational topics in **CSE 220: Signals and Linear Systems Sessional**.

---

## Practice Sets Overview

| Module | Topic | Core Contents | Key Deliverables |
| :--- | :--- | :--- | :--- |
| [**Practice_01_Python**](./Practice_01_Python/) | **Python & NumPy Basics** | 4 core problems: array generation, matrix arithmetic, signal normalization, and trigonometric waveform synthesis | `problem1.py`–`problem4.py`, `PythonPractice.pdf` |
| [**Practice_02_Convolution**](./Practice_02_Convolution/) | **Discrete LTI Convolution** | Discrete linear convolution algorithm, indexing boundaries, analytical derivation vs. computational verification | `2305025-practice.py`, `fixed_soln.py`, solutions PDF |
| [**Practice_03_Sampling**](./Practice_03_Sampling/) | **Sampling & DSP Toolkit** | Master 24-section template (`template.py`), 7-figure visual demo suite (`test_template.py`), and 11 Fast Fourier Transform modules (`/fft`) | Complete 400-line documentation, Mahdi/Sami/GPT problem sets |

---

## Recommended Study Path

1. **Start with [`Practice_01_Python`](./Practice_01_Python/)** to solidify array indexing, vectorized boolean masking, and plotting.
2. **Move to [`Practice_02_Convolution`](./Practice_02_Convolution/)** to master finite-length discrete convolution without relying on built-in black-box functions.
3. **Master [`Practice_03_Sampling`](./Practice_03_Sampling/)** before exams to gain proficiency in aliasing boundaries, Whittaker-Shannon sinc reconstruction, ZOH, and FFT amplitude calibration.
