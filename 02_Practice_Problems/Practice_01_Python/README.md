# Practice Set 01: Python, NumPy & Matplotlib Basics

> **Source Document:** [`PythonPractice.pdf`](./PythonPractice.pdf)

---

## Overview

This introductory practice set covers basic Python data structures, standard algorithms, numerical computing with NumPy, and multi-panel data visualization with Matplotlib.

---

## Problem Breakdown

| Script | Title / Concept | Description |
| :--- | :--- | :--- |
| [`problem1.py`](./problem1.py) | **Hospital Patient Triage Aggregator** | Parses patient visit entries, aggregates total treatment time and cumulative severity score per patient using Python dictionaries, and ranks the top-priority patient. |
| [`problem2.py`](./problem2.py) | **Array Operations & Thresholding** | Demonstrates NumPy array manipulation, filtering, and conditional calculations. |
| [`problem3.py`](./problem3.py) | **Matrix Computations** | 2D array transformations, row/column reductions, and matrix arithmetic. |
| [`problem4.py`](./problem4.py) | **4-Quadrant Multi-Panel Plotting** | Creates a comprehensive $2 \times 2$ subplot figure comparing regional branch performance over 12 months using line plots, bar charts, scatter plots, and horizontal bar charts. Outputs `p4_output.png`. |

---

## How to Run

```bash
python3 problem1.py
python3 problem2.py
python3 problem3.py
python3 problem4.py
```
