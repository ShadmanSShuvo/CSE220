## Key Skills Tested in Past Online 1 Exams

1. **Piecewise Continuous Function Evaluation**: Constructing multi-segment piecewise functions with exact boolean masks in NumPy.
2. **Signal Shifting, Reversal, and Scaling**: Evaluating $y(t) = x(\alpha t + \beta)$ without introducing off-grid sampling artifacts.
3. **Linear Interpolation**: Handling non-integer query time points $\tau$ through nearest-neighbor bounds averaging.
